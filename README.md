# MyTelegramGptBot

📥 Как клонировать репозиторий:
bash
Копировать
Редактировать
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name


 ▶️ Как запустить бота:
Установите зависимости:

bash
Копировать
Редактировать
pip install -r requirements.txt
Убедитесь, что у вас есть токены:

telegram-token.txt — токен вашего Telegram-бота.

openai-token.txt — токен OpenAI GPT.


Запустите бота:

bash
Копировать
Редактировать
python main.py


 🤖 Что умеет бот:
/gpt — чат с GPT (на основе OpenAI).

/random — случайный факт.

/talk — диалог с известной личностью (например, Игорем Войтенко).

/quiz — квиз по известным спортсменам.

Генерация тренировок и рекомендаций.

Ведение логов для всех действий.
